问题执行链路


                  
从问题进入到最终回答的可审计链路：语义分析、路线分流、证据检索、图谱/社区上下文、证据校验和答案生成。


                


                GraphRAG / Query Plan

              


              


                


                  01 INPUT

                  提问与参数

                  
读取问题、集合名、Graph DB、top_k=100、检索模式和 LLM 配置。


                


                


                


                  02 ROUTER

                  Query Router / 问题分流

                  
判断是向量问答、局部实体追问、全局汇总，还是跨资料多跳故障归因。


                


                


                


                  03 SOURCES

                  证据源选择

                  
读取动力装备文本集合、GraphStore、社区摘要；普通 top-k 只作补充，不作为全局结论依据。


                


                


                


                  04 FULL SCAN

                  跨文档全量扫描

                  
枚举燃机、汽轮机、锅炉、辅机等设备相关资料，按设备、部件、故障、参数和处置措施建立证据链。


                


                


                


                  05 EVIDENCE

                  原文证据审计

                  
只保留带来源文件、页码/章节、chunk_id 或 record_id 的原文证据；无原文则只能标为证据不足。


                


                


                


                  06 OUTPUT

                  LLM 判级与汇总

                  
按设备、部件、故障原因、影响范围和建议措施输出结论，并说明每条结论对应的证据来源。


                


              


              


                


                  VECTOR_ONLY: 普通语义片段问答

                  LOCAL_SEARCH: 单个实体邻域追问

                  GLOBAL_SEARCH: 跨社区/全局总结

                  CROSS_DOC_SCAN: 跨资料全量证据扫描
