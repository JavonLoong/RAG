## 请主账号管理员处理

建议主账号管理员执行以下最小授权，不需要授予财务、下单或全局系统管理员权限：

1. 登录百度智能云主账号。
2. 进入“多用户访问控制 IAM → 用户管理 → 子用户”。
3. 选择子用户 `graphrag`，打开“权限信息”。
4. 添加“文字识别 OCR / AI 开放平台”相关的控制台访问和应用管理权限。
5. 允许该子用户查看 OCR 资源、查看/创建应用并调用已选 OCR 接口。
6. 确认主账号已经实名认证，并确认已购买资源确实属于“文字识别 OCR”。
7. 二选一：
   - 主账号创建 `graphrag-ocr-benchmark` 应用，再让子用户使用；或
   - 授予子用户创建 OCR 应用的权限，由项目成员创建。

应用一期只需勾选：

- 通用文字识别（标准含位置版）；
- 通用文字识别（高精度含位置版）；
- 办公文档识别；
- 表格文字识别 V2。

暂时不要开通按量后付费、购买新的资源包或授予订单权限。先使用老师已购买的资源或免费测试资源，核实效果后再决定。

## 凭证处理要求

- API Key 和 Secret Key 不要发送到群聊、邮件正文或项目仓库；
- 由管理员在本机设置环境变量，或者让有权限的子用户在控制台读取；
- 代码只读取 `BAIDU_OCR_API_KEY`、`BAIDU_OCR_SECRET_KEY`，不会把凭证写入报告；
- 完成测试后应轮换已经公开发送过的登录密码。

## 本地基线已经完成

在等待云端授权期间，项目已安装并验证：

- RapidOCR `3.8.4`；
- ONNX Runtime `1.24.4`；
- 4 张程序生成、允许云端测试的中文技术页；
- 正文、低清正文、表格和双栏四类人工金标。

本地 RapidOCR 实测：

| 类别 | CER | 判断 |
|---|---:|---|
| 清晰正文 | 0.0000 | 文字完全匹配 |
| 低清正文 | 0.0000 | 文字完全匹配 |
| 表格文字 | 0.0000 | 单元格文字全部匹配，但没有恢复行列结构，仍需表格专用识别 |
| 双栏原始顺序 | 0.6160 | 左右栏按同一水平线交错输出，阅读顺序错误 |
| 双栏分栏重排候选 | 0.0000 | 先左栏后右栏后与金标匹配；仍保留原始框顺序并要求人工确认 |

这说明本地 OCR 当前的主要短板不是清晰中文正文，而是表格结构和双栏阅读顺序。下一步百度云对比应重点看“办公文档识别、表格识别和含位置接口”，不能只比较通用正文识别。
