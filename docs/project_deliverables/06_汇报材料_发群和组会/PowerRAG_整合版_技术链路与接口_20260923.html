本地工作台。手册和扫描件进来，读成带页码的证据，再检索、构图、问答、出故障分析表。现网入口是 current_console。Electron 不用。RAG交付 是历史快照。

一条线

资料进来，读成带页码的证据。审过再入库。只从已发布资料构图，关系绑回原页——相对把资料直接丢给大模型作答的优势。问答走检索或沿图。只从已发布图出表，字段带证据。最后走验收。

两套编号

界面：M1 资料接入 → M2 知识组织 → M3 图谱问答 → M4 可信交付 → M5 验收。
治理：解析 → 入库 → 构图 → 出表。界面 M4 对应治理全段。界面 M5 是验收台。
